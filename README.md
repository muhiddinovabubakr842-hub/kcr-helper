# Политех Помощник

Конструктор учебных работ для студентов в Худжанде.

- Гость просматривает публичную страницу и демонстрационный документ.
- Вход через ChatGPT открывает редактор.
- Файлы DOCX обрабатываются в браузере: текст, заголовки и PNG/JPEG.
- Таблицы импортируются как редактируемые строки текста. Это импорт содержимого с новым оформлением, а не точное сохранение исходной вёрстки.
- Черновики изолированы по аккаунтам в IndexedDB. Старый черновик можно перенести явно через уведомление.
- Русский/таджикский интерфейс, инструкции под полями, поиск настроек, мобильные вкладки.
- Шаблоны титульника, содержание, колонтитулы, параметры шрифта, Word/PDF/JSON.

## Структура

- web/ — интерфейс, импорт и экспорт.
- worker/index.js — маршруты гостя, редактора, сессии и ресурсов.
- scripts/build.mjs — собирает все ресурсы в один Worker ESM.
- tests/ — тесты импорта, интерфейса и серверных ограничений.

## Проверка и сборка

Node 20+:

    npm ci
    npm test
    npm run build

dist/server/index.js — готовый Worker с включёнными ресурсами.
Исходный web/index.html можно использовать локально; там действует локальный режим без онлайн-входа и ресурсов.

## Локальный помощник

Работает в браузере без внешнего ИИ и без API-ключей.
Проверяет заполнение основных полей, показывает структуру работы и очищает
повторные пробелы и пустые строки в обычном тексте.
Пользователь сначала просматривает результат, затем применяет или отменяет замену.
Смысл, факты, орфографию и требования кафедры нужно проверять самостоятельно.

## Свободный рабочий стол

На экране шире 1100 px панель ввода и предпросмотр перемещаются за ручку ⠿.
Угол ◢ меняет размер. На клавиатуре: стрелки на ручке, Shift для большого шага.
Расположение сохраняется в браузере. «Свободные панели» переключает в сетку,
«Сбросить панели» возвращает начальное положение.

Лист перемещается независимо в режиме «Рука». Доступны 25–200%, Ctrl/Meta + колесо,
щипок двумя пальцами, кнопки ±, «Вписать A4» и 100%.
На сфокусированной области листа: стрелки перемещают, ± масштабируют, 0 вписывает.
Эти координаты относятся только к интерфейсу и не меняют Word/PDF.

«⛶ На весь экран» раскрывает предпросмотр в полноэкранном окне на компьютере
и телефоне. В нём доступны страницы, перемещение, масштаб и экспорт.
«Закрыть» или Esc возвращает редактор с прежним масштабом и положением листа.
Окно поддерживает навигацию Tab, возврат фокуса и блокирует фоновые элементы.

## Новый титульный шаблон

В форме выбери «Титульный лист A4 — поля 30/15/20/20 мм».
Он использует Times New Roman 12/14 пт, заголовок 16 пт полужирный.
Министерство, учебное заведение, утверждение, студент и преподаватель редактируются.
В Word город/год закреплены в нижней части листа отдельным текстовым фреймом.
При слишком длинных названиях предпросмотр показывает предупреждение о переполнении.

Поля и состав учебного титульника реализованы по заданию пользователя.

нужно сверять с методическими указаниями кафедры. Проект не является сертификатом
соответствия всем положениям ГОСТ 7.32 или ГОСТ 2.105.
